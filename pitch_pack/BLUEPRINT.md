## Technical Whitepaper

**File:** `whitepaper/wheeler_memory_whitepaper.md`
**Format:** Academic-style document, ~30–40 pages, pandoc → PDF.

### Chapter Outline (v0.3.6)

#### Title
"Wheeler Memory: A Cellular-Automaton Substrate for Reconstructive Episodic Memory with Two-Tier Recall and Per-Basin Temporal Stability."

#### Abstract (200–300 words)
Problem → CA substrate → three-grid interference → two-tier recall → per-basin plasticity →
honest empirical results (including chance-level MMLU L3).

#### 1. Introduction (2–3 pages)
- Motivation: LLM memory is retrieval-based, conflates identity with content, has no epistemic state
- Gap: no native (no pretrained models) substrate for reconstructive memory
- Contributions: CA substrate; three-grid interference (v0.3.1); two-tier recall + per-basin T (v0.3.6); native distributional encoder; honest MMLU baseline
- Paper roadmap

#### 2. Related Work (3–4 pages)
- 2.1 Vector Databases (Pinecone, Weaviate, Qdrant)
- 2.2 RAG and its limits
- 2.3 Episodic memory in cognitive science (Loftus on reconstruction; consolidation literature)
- 2.4 CA in computing (Conway, Wolfram), associative memories (Hopfield, modern Hopfield)
- 2.5 Information theory & physics (Wheeler's "It from Bit"; IIT)

#### 3. Methodology (8–10 pages, the bulk of the rewrite)
- 3.1 The CA substrate: 3-state rule, von Neumann topology, push/slope coefficients, convergence in 5–14 ticks, four end states
- 3.2 Encoders: hippocampus n-gram RI, **Context-RI** (601M-word distributional), language wheeler, optional MiniLM
- 3.3 Storage: chunked layout, fcntl-locked index.json, Pearson + spatial similarity
- 3.4 **Two-tier recall (v0.3.6)**: `recognize` (raw query frame, no CA loop), `reconstruct_from_seed` (warm-start blend + re-evolve)
- 3.5 **Per-basin Temporal Stability**: T-EMA, drift gating `(1−T)·base_rate`, persistence
- 3.6 **Three-grid interference**: corpus × experiential × (1−|SCM|), four states (GROUNDED / ABSORBED / UNCONSOLIDATED / CONTESTED)
- 3.7 SCM dynamics: hardening, recall-driven feedback (κ EMA), telemetry
- 3.8 Cortex L1/L2/L3: graph topology, settlement CA, numpy SGD classifier
- 3.9 Temperature & lifecycle: decay formula, tiers, sleep consolidation, eviction
- 3.10 Reconstructive recall: blend formula, α tuning

#### 4. System Architecture (4–5 pages)
- 4.1 Module structure (44 modules grouped)
- 4.2 Sacred files (`hashing.py`, `storage.py`, `chunking.py`, `rotation.py`, `bench_quality.py` TEST_INPUTS)
- 4.3 GPU dispatch (`accel/ca.py` + `accel/hip/`); 71× speedup
- 4.4 Agent integration (Ollama-driven `wheeler-primary`)
- 4.5 CLI surface (16 commands, no wheeler-ui)

#### 5. Experimental Validation (8–10 pages)
- 5.1 Test suite (775 tests, no regressions in v0.3.6)
- 5.2 Convergence properties (CA dynamics tuning, oscillation rate)
- 5.3 Diversity & paraphrase reports
- 5.4 Two-tier benchmark (`bench_recall_warm_vs_cold.py`): 3 distance bands, ~2× ticks reduction; recognition rate by band
- 5.5 Per-basin T trajectory (5-recall smoke test: 0 → 0.10 → 0.19 → 0.27 → 0.34 → 0.40)
- 5.6 SimLex-999 (Context-RI ρ=+0.255 evolved; per-POS breakdown)
- 5.7 Apple Test (semantic holdout)
- 5.8 MMLU (honest, including L3-at-chance)

#### 6. Discussion (3–4 pages)
- 6.1 Strengths: native, local, reconstructive, two-tier
- 6.2 Limitations: O(n) Pearson search, no multimodal yet, L3 stalls at chance, verb semantics weak, SCM scalar-collapse issue
- 6.3 Theoretical implications: "It from Bit" applied to epistemology; emergent interference states
- 6.4 Comparison to vector DBs and RAG

#### 7. Conclusion & Future Work (2–3 pages)
- Reconstruction scoring (next MMLU mode)
- Sleep consolidation of T (offline pass)
- SCM scoring fix (spatial product replaces scalar mean_openness)
- Multimodal encoders

#### Appendices
- A: Algorithm pseudocode (CA step, recognize, reconstruct, drift)
- B: Mathematical details (temperature derivation, Pearson properties, EMA stability)
- C: Implementation notes (numpy, HIP kernel, fcntl locking)
- D: References (Wheeler, Loftus, Wolfram, Tononi, Conway, Hopfield, Mikolov for context-RI inspiration)
