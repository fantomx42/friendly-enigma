# scripts/experiments/ — Theory Test Harnesses

Standalone scripts that exercise the `wheeler_memory/theories/` modules. Each maps 1:1 to a theory module.

- **test_basin.py** — Basin width experiments
- **test_lichtenberg.py** — Topology visualization
- **test_metrics.py** — Topology quality metrics
- **test_resonance.py** — Resonance querying
- **test_structured.py** — Structured theory building
- **test_synthesis.py** — Apple test / gap synthesis

These are exploratory scripts, not pytest tests. They produce output for manual inspection and research notes.
