Architecture Summary
====================

Network: 21 → 128(ReLU) → 64(ReLU) → 4(softmax)
Parameters: 11,460

Input Features (21 dimensions):
- Settlement: (K,) from L2 diffusion CA
- Choice Similarities: (4,) Pearson r vs question attractor
- SCM Layers: (7,) [Temperature, Salience, Energy, Integration, Polarity, NetWarrant, ExplanationReadiness]

Output: (4,) softmax probabilities for A/B/C/D

Implementation Details
======================

cortex_classifier.py:
- Xavier weight initialization (scale by 1/sqrt(fan_in))
- ReLU activations with efficient derivative masking
- Numerically stable softmax (subtract max before exp)
- Manual backprop through 3-layer network
  * Softmax + cross-entropy gradient at output
  * Backprop through ReLU layers with masking
  * SGD weight updates
- np.savez/np.load for persistence

train_cortex_classifier.py:
- Loads MMLU dev+validation splits
- Encodes with hippocampus_to_frame_batch
- Retrieves top-K attractors via AttractorCache
- Computes Pearson correlations for choice similarities
- Runs cortex_reason for settlement computation
- Computes SCM for 7-layer coherence scores
- Builds (N, 21) feature matrix
- Trains with SGD, validation split
- Prints loss/accuracy per epoch
- Saves weights to .npz

Usage Examples
==============

Basic training:
  python scripts/train_cortex_classifier.py

With 10 samples per subject:
  python scripts/train_cortex_classifier.py --samples-per-subject 10

Specific subjects only:
  python scripts/train_cortex_classifier.py --subjects abstract_algebra college_physics

Custom learning rate and epochs:
  python scripts/train_cortex_classifier.py --epochs 5 --lr 0.0001

Custom output path:
  python scripts/train_cortex_classifier.py --output /data/my_classifier.npz

Integration with Cortex Module
==============================

cortex.py provides:
- compute_adjacency(attractors) → (K, K) Pearson correlation matrix
- find_clusters(adj, threshold) → (K,) cluster labels
- find_bridges(adj, clusters, threshold) → (K,) bool bridges
- build_graph(attractors, similarities, ...) → GraphReasoning
- settle(opinions, adjacency, ...) → dict with settled opinions

cortex_scm.py provides:
- score_temperature(similarities) → float
- score_salience(similarities) → float
- score_energy(settled, prev_settled) → float
- score_integration(adjacency, clusters) → float
- score_polarity(adjacency) → float
- compute_net_warrant(...) → float
- score_explanation_readiness(settled, choice_similarity) → float
- compute_scm(...) → SCMResult with all 7 layers + classification

The classifier learns to combine these signals into answer selection.
